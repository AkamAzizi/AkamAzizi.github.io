## 🚀 Featured Projects

### Algorithm Implementation
- **[Intelligent Sudoku Solver](https://github.com/akamazizi/sudoku-solver)**: Advanced Sudoku solver built with Python using recursive backtracking and constraint propagation. Features comprehensive test suite with 10+ puzzle variations, performance timing analysis, and optimization techniques for solving puzzles of varying difficulty levels.

### Artificial Intelligence
- **[MiniMax Mancala AI](https://github.com/akamazizi/minimax-mancala-ai)**: Sophisticated AI opponent for the classic Mancala board game implementing the MiniMax algorithm with alpha-beta pruning optimization. Features multiple difficulty levels, strategic gameplay decision-making, and efficient game tree evaluation.

### Optimization Algorithms
- **[Knapsack Optimization Suite](https://github.com/akamazizi/knapsack-solver)**: Comprehensive solution to the 0/1 Knapsack optimization problem featuring both BFS and DFS algorithm implementations. Includes detailed performance comparison analysis, visualization of solution paths, and benchmarking tools.

### Game Development
- **[Classic Snake Game](https://github.com/AkamAzizi/SnakeGame)**: Faithful recreation of the classic arcade Snake game with modern enhancements. Features smooth gameplay mechanics, progressive difficulty scaling, high score tracking, and responsive collision detection.
- **[Flappy Bird Clone](https://github.com/akamazizi/Flappy-bird-Clone)**: Engaging recreation of the popular Flappy Bird game with enhanced graphics and smooth gameplay mechanics. Implements physics-based movement, collision detection, and progressive difficulty.

### Business Applications
- **[AI Resume Analyzer](https://github.com/AkamAzizi/ai-resume-analyzer)**: Full-stack application that helps job seekers match their resumes against job descriptions. Built with **FastAPI, scikit-learn, spaCy** on the backend and **React + TypeScript + Material UI** on the frontend. Provides a match score and highlights missing keywords, simulating Applicant Tracking Systems (ATS).
- **[Barbershop Queue Manager](https://github.com/AkamAzizi/barbershop-queue-app)**: Professional queue management system designed to streamline customer flow and enhance communication in barbershop environments. Features real-time wait time estimation and customer notifications.
- **[Smart To-Do Manager](https://github.com/akamazizi/to-do-list)**: Feature-rich task management application built with Python and Tkinter. Includes priority setting, deadline tracking, category organization, and data persistence.
